# SEO Crawl Audit 0.15.1

This patch release fixes the Local scan history chart so its colored lines are
not filled as polygons. Runs made on the same day show distinct time labels,
and a single run no longer creates overlapping endpoint labels.

The example report now includes eight synthetic history points to illustrate
the trend view. README screenshots for Overview, Site Metrics, Issues, and Page
Explorer have been refreshed. These example values are not live measurements
of the example website.

SnapshotV2, issue fingerprints, rules, CLI commands, and exit codes are
unchanged. The GitHub Action `v0` moving tag is not changed by this release.
